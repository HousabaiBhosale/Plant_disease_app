# PLANT DISEASE APP - EXECUTION GUIDE

This guide explains how to run the three components of the project:
1. Backend (FastAPI Server)
2. Admin Dashboard (PHP Dashboard or React Dashboard)
3. Flutter Mobile Application

---

## 1. RUNNING THE BACKEND (FastAPI Server)

To start the backend, you must first navigate to the `plant_disease_backend` directory and activate the virtual environment so that the required packages (like `uvicorn`, `fastapi`, `tensorflow`) are available.

### Command Line / PowerShell:
```powershell
# Step 1: Navigate to the backend directory
cd C:\Users\HP\PlantDiseaseApp\plant_disease_backend

# Step 2: Activate the Python virtual environment
..\venv\Scripts\activate

# Step 3: Run the FastAPI backend server
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Alternatively, you can just run the pre-configured batch file:
```powershell
cd C:\Users\HP\PlantDiseaseApp\plant_disease_backend
run_backend.bat
```

---

## 2. RUNNING THE ADMIN DASHBOARD

### Option A: PHP Dashboard (Recommended / Newly Migrated)
The PHP dashboard is served locally using PHP's built-in development server (or Apache/XAMPP).

#### Command Line / PowerShell:
```powershell
# Step 1: Navigate to the php-dashboard directory
cd C:\Users\HP\PlantDiseaseApp\php-dashboard

# Step 2: Start the PHP development server on port 8080
php -S localhost:8080
```
Then open your browser and navigate to: http://localhost:8080

Alternatively, you can run the pre-configured batch script:
```powershell
cd C:\Users\HP\PlantDiseaseApp\php-dashboard
run_dashboard.bat
```

#### Option B: React Dashboard (Legacy)
If you still wish to run the legacy React-based dashboard:
```powershell
# Step 1: Navigate to the React dashboard directory
cd C:\Users\HP\PlantDiseaseApp\plant-disease-dashboard

# Step 2: Start the React development server
npm start
```

## 3. RUNNING THE FLUTTER APP

Before running the Flutter app, make sure your Android device/emulator is connected. If you are using a physical Android device, establish the ADB connection tunnel first:

### Step 1: Establish ADB Reverse Port Forwarding (for physical devices)
This routes traffic from the device's port 8000 to the computer's port 8000:
```powershell
"C:\Users\HP\AppData\Local\Android\Sdk\platform-tools\adb.exe" reverse tcp:8000 tcp:8000
```

### Step 2: Navigate and Run the Flutter App
```powershell
# Navigate to the Flutter project folder
cd C:\Users\HP\PlantDiseaseApp\plant_disease_app

# Run the application
flutter run
```
